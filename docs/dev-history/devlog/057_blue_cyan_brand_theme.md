# Devlog 057: Paleta azul e ciano para a interface Manga Garden

## Objetivo

Alinhar as cores de destaque da extensão à nova identidade visual azul e ciano do ícone, substituindo o rosa/vermelho usado como cor principal.

## Alterações

- Atualizadas as cores de destaque dos temas claro e escuro.
- Atualizados os acentos do estúdio, dos controles de tradução e dos elementos flutuantes.
- Mantido o vermelho para estados de erro e falha, preservando seu significado de alerta.
- Atualizados os testes que verificam a cor de marca dos controles.

## Validação

- Build de produção e testes focados da interface executados após as alterações.
