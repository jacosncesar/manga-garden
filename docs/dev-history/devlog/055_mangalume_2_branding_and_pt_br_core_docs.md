# Devlog 055: Marca MangaLume 2.0 e documentação principal em pt-BR

## Objetivo

Iniciar a adaptação visual do projeto para MangaLume 2.0 e tornar os documentos principais de entrada mais acessíveis a leitores brasileiros.

## Alterações

- Atualizado o nome exibido pela extensão e por elementos de marca da interface.
- Traduzidos para português brasileiro o README principal, o índice de documentação e o guia de configuração do ambiente.
- Preservados nomes técnicos, comandos, caminhos, identificadores e avisos legais.
- Mantida a configuração do `.gitignore`, que já excluía dependências, artefatos de compilação e arquivos locais.
- Mantidos o remoto Git e o histórico existentes; trocar o nome visível não configura um novo repositório.

## Escopo desta etapa

Esta é a primeira etapa da tradução. Os demais documentos Markdown, incluindo ADRs, planos e registros históricos, ainda precisam ser traduzidos em etapas posteriores.

## Observações

A alteração da marca não troca recursos externos configurados no projeto, como o cliente OAuth, o backend compartilhado ou links de publicação. Esses recursos precisam ser avaliados separadamente antes de distribuir uma versão independente.
